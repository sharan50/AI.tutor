The D6 boundary: where exemplar conditioning attaches

One field, one renderer slot, one retriever. The seam is specified now so that exercising D6 is a configuration change plus a licence, not a rewrite under time pressure.

The interface

Exemplar conditioning attaches at exactly one place: the exemplars field of the style object, which is null in every shipped preset at launch.

// Launch (D5): always null.
"exemplars": null

// Under D6, and only with a content licence in force:
"exemplars": {
  "corpus_id":     "lic.creatorref.v1",
  "licence_id":    "CL-2027-0xx",
  "licence_expiry": "2028-06-30",
  "retrieval":     "objective_matched",   // k segments matched to the objective
  "k":             3,
  "max_quote_tokens": 0                   // set by the licence; 0 = no verbatim reuse
}

When the field is non-null, the renderer populates a slot that is otherwise omitted entirely:

render(object, renderer_version) -> style_card_text
  [dimension instructions from the twelve bands]     // unchanged
  [register note]                                    // unchanged
  [EXEMPLAR SLOT: present only if object.exemplars != null]

What changes when D6 is exercised

AreaChange
LicenceName and likeness is no longer sufficient. A content licence is required, covering reproduction, adaptation and machine processing of specified material, for a defined term. This is Schedule 2 of the heads of terms and it is drafted but unexercised.
StorageA licensed corpus store appears, holding creator material with per-segment provenance, licence identifier and an expiry that is enforced by the store rather than by a person remembering.
Kill switchGains two steps: invalidation of cached prompt fragments, and deletion of the corpus and every derived index. The 15-minute disable is unaffected; what slows and complicates is the deletion behind it, and the figures are in 04. This is the single largest operational cost of D6.
EvaluationT-STY-04 becomes live and blocking. A leakage failure is treated as a rights incident, not a quality bug.
LabellingThe on-screen line changes, because "does not write these answers" is harder to sustain when the creator's material is conditioning them. The revised wording is a counsel question, listed as OI-6 in 14.
Rating protocolExtended, not replaced. The twelve dimensions are still fitted by human raters; exemplars are additional, not a substitute.

What does not change

This list is the point of designing the boundary now.

  • The schema of the twelve dimensions, and every value fitted under it. Existing presets keep working.
  • The renderer interface and its contract. Only a slot is populated.
  • The student adjustment controls and the clamps.
  • The content plane: the item bank, retrieval, the verifier and the accuracy floor. Exemplars condition style and are never a source for a curricular claim. The verifier does not accept an exemplar as grounding.
  • D8 holds absolutely. No LoRAs, no fine-tuned weights, no adapters carrying creator style, under D5 or D6. Weights cannot be cleanly revoked and a kill switch that requires retraining is not a kill switch.

The exemplar retriever is specified to return objective-matched segments as style context only, and the verifier is specified to reject any curricular claim whose only support is an exemplar. Without that second half, D6 quietly reintroduces ungrounded content through the style path and P2 fails silently. The seam is designed so the content gate sits downstream of it and cannot be bypassed.
