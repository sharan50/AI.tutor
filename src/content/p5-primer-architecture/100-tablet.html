The tablet

The Primer is its own tablet, one per child, with nothing else on it (D105). It starts in the Primer, has no browser, no other apps and no notifications, and keeps no conversation. The dedicated tablet is designed alongside PM4 and made only after PM4's evidence; PM4 itself runs on a stand-in (P6).

The tablet has no camera, and its microphone listens only while the child holds the talk key, with the screen showing plainly that it is listening: no wake word, and nothing listening in the background. The ICO's guidance on connected devices points the same way, Assumed (CV-37).

PM4 runs on a stand-in, which is weaker. The built Primer is first run on a tablet already on sale, one per pilot child, locked to the Primer by its operating system's single-app controls, while the dedicated tablet is designed in parallel (P6). The Primer draws its own keyboard there, so the system's dictation never opens, and the lock switches off the system's own voice assistant and wake word. T-PRM-13 adds a software check of every path that can open the microphone, run on each stand-in before any child uses it and on every software release, the stand-in's own system updates included, because the talk key there is software and a release can change what opens the microphone. A stand-in without a camera is chosen for PM4. If none suits, the owner chooses between one whose camera is switched off and covered, which T-PRM-13 would not pass, and pilot units of the dedicated design (P4). The stand-in is a step towards the tablet the films show, not that tablet.

What making the tablet costs, who makes it, and how it is supplied, repaired and certified are P6's; RP7 is the risk that families will not pay for it.
