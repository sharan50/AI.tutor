Cost per session

Cost per session is not known and is not estimated here. It depends on how many turns a session has, which is not known: one question is a design target of three to six minutes (D112), "Keep going" extends it within the time cap set from PM3's pilot (D103), and the pace sets how many turns fit. It depends on the calls each turn makes, which for the Primer are recognition when the child speaks, triage, matching, the generator, up to seven verifier checks and the voice. And it depends on the review at the close.

            + generate(ctx_tokens, out)    // pinned generator
            + verify(checks)               // up to seven, a to g
            + speak(spoken_length) ]       // the voice; D30 does not bound it
  + review                                 // once, at the close (D107)
  + explainers x draw                      // ~0, drawn on the tablet (D28, D111)
  + storage                                // the summaries, the per-turn log, the queues,
                                           // the flagged hold, the safeguarding count and
                                           // the escalation records; no turn of the child's,
                                           // whole or in part, after the close outside the
                                           // read-back, except a flagged exchange until
                                           // its review closes (D104, D107)

where, per turn:
  ctx_tokens = system_fixed + wording_card + entries + summaries
             + child_words                 // this conversation, whole, until the close
             + window                      // the Primer's earlier turns, summarised (D30)

D30's bounded summary does not cover the child's words. The read-back and its check need what the child actually said, so the child's words stay whole in the window until the close, bounded by the time cap, and only the Primer's own earlier turns are summarised, as the ledger's note on D30 records. Cost per turn therefore grows with what the child has said, up to the bound the time cap sets; how large the child's words grow is Unknown until PM4.
