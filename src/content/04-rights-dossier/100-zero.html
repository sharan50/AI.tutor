Zero-persona operation, proved rather than asserted

D11 is a hard requirement, and this is where the proof of it belongs, because it is a rights property before it is a product property. The claim is: no single unsigned contract can block launch, and no signed contract ending can stop the service.

What makes it true is structural rather than aspirational.

  1. Every preset is an archetype by construction. A licensed preset is an archetype's parameter vector with a name attached and, at most, twelve fitted values. Remove the name and the vector and an archetype remains. The two worked vectors in 02 are archetypes, not licensed presets, and they are the ones used throughout this repository.
  2. The catalogue ships archetypes on day one regardless. D14 requires named presets and unnamed archetypes to ship simultaneously, so the archetype path is not a fallback that has never been exercised; it is half the launch product and half the experiment.
  3. The fallback target is defined per preset. Every licensed preset names the archetype it degrades to. The kill switch has somewhere to send a live session at T+16 minutes because that target is a required field, not a runtime decision.
  4. No content depends on a persona. The item bank, the verifier and the accuracy floor sit entirely in the content plane. Personas live in the style plane. Every accuracy promise in 01 holds with zero personas signed, because none of them references a persona.
  5. The test exists. Decision D23 T-ZERO-01: the full regression battery T-REG-01 is run with the persona registry empty, on every release, as a blocking check. If the product cannot pass its own content tests with no personas configured, D11 has quietly stopped being true and the release does not ship. Status: specified, not run.

Point 5 is the difference between proving and asserting. Without a blocking test that runs with an empty registry, D11 degrades into a claim that was true on the day it was written, and the first persona-dependent code path added under delivery pressure would falsify it silently.
