Four details that are not obvious and are each doing work:

  • Preset.enabled is the entire kill switch. One boolean, read per request.
  • Session.preset_snapshot records the style object as it was at session start, so a transcript can be explained after a preset changes. For a licensed preset it is purged on the same seven-day line as the object itself, and the transcript thereafter carries only the neutral preset identifier. An earlier draft had the snapshot surviving termination as company work product; that is the exact retention the heads of terms rejects, and a snapshot that outlived the licence would have made the deletion promise false while appearing to keep it.
  • Turn.style_signatures is written at logging time, which is what makes T-STY-01 a measurement over live traffic rather than a separate test harness.
  • Account.verification holds a boolean and a reference. There is no date of birth field in this schema, anywhere, by design.
