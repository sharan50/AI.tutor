Architecture

Buy the model. Own the item bank, the style objects and the verification layer. The moat is validated content and outcome evidence, not weights.

Shape

A hosted frontier model behind an abstraction thin enough to swap providers, with retrieval over the item bank, a style-card layer generated from the style object, and a safety layer that sits outside both and cannot be reached by either.

Paper assembly and calibration

The assessment service receives a blueprint rather than an open-ended request: selected exam board (for example AQA or Pearson Edexcel), qualification, specification version, tier, objectives, marks, time and target difficulty mix. It rejects any item that is not validated and calibrated for that exact board-version-tier combination, then emits the paper alongside the item-level validated mark scheme and stores the exact item IDs and versions used. A paper is therefore reproducible even after its items are retired.

A separate calibration record connects observed learner performance to item and paper difficulty for one board-version-tier combination. The grade-range service reads only that record and refuses to run when the board match, sample, blueprint match or specification version is inadequate. It returns a range with the calibration version and evidence date, never a single grade or a label that resembles an awarding organisation's boundary.

The important separation is between generation and estimation. The model may help present feedback, but it cannot decide a mark scheme, difficulty or grade range from its own confidence. Those claims are grounded in validated item records and observed performance, with an explicit no-estimate state when the evidence is thin.

The turn

What happens between a student sending a message and seeing a reply. Stated as a sequence because the ordering carries the guarantees.

  • Safety pre-check on the student's message, against the student's age band. Outside academic scope routes to the escalation path in document 05 and the turn ends here. The style object is not loaded and cannot influence this.
  • Objective resolution: the message plus session state resolves to one objective_ref. Unresolvable means asking, not guessing.
  • Retrieval of live items on that objective. Items not in state live are invisible to retrieval, which is where the provenance rule is actually enforced.
  • Style card render from the style object currently in force, including any student dial adjustments.
  • Generation, conditioned on retrieved items and the style card, with the item ids carried through so the reply is traceable.
  • Safety post-check on the output, again with no reference to the style object.
  • Log: turn, objective, item ids used, style object version, conformance observables. This log is what makes both the accuracy claim and the style claim checkable after the fact.

The isolation of the safety layer from the style object is a hard architectural boundary, not a convention, and it is tested rather than asserted. The test: run the full safety evaluation set under all five archetypes and every live named preset, and require identical outcomes. A divergence is a release blocker.

Kill switch

Because no creator material is ingested and no weights carry style, revoking a preset is a record update rather than a retraining job. The 60 minutes promised in document 04 decomposes as follows, which is what makes the number checkable rather than aspirational.

The binding constraint is the style-card cache TTL, which is therefore set below the promise rather than tuned for cost. The 60-minute figure is still a design target and not a measurement; it becomes measurable the moment the caching layer exists, and it should be measured before the promise is made to any creator in writing.

Evaluation harness

Three suites, run on every release, reported together.

  • Accuracy against live items, human-scored on a sample per document 03.
  • Style conformance against the style object in force, on the observables in document 02, with the transcripts in document 01 as reference behaviour.
  • Safety isolation, requiring identical safety outcomes across all styles.

Still unwritten: the data model in detail, the retrieval strategy, assessment-calibration thresholds, cost per session, and the latency budget. Cost per session is the one that matters commercially, and it is blocked on the same launch-scope decision as documents 10 and 11, because average items retrieved per turn and the assessment-calibration workload both depend on bank density.
